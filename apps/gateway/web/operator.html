Supply-chain console

The mid-chain actors — aggregator, processor, accredited lab, GMP manufacturer. Each action writes a real EPCIS 2.0 event and is gated by chaincode: weight variance, mass balance, incentive-independent endorsement, and the CP-7 all-inputs-passed formulation gate.

Aggregate collected lots & re-weigh (CP-3)

Pick incoming lots; the IoT weighbridge check holds the batch if measured vs declared weight varies > ±10%. 🟡 weigh input

Merge N lots → 1 output (mass balance)

The mixing problem, solved: Σ(inputs)×(1−loss) must equal the output ±5%, or the batch is held for MASS_BALANCE_VIOLATION. Every output keeps traceable links to all inputs with proportions.
Tick the lots to combine and set the kg drawn from each.

Quality test — dual-endorsed (CP-5 / CP-6)

Requires the testing lab plus an incentive-independent second signer (NMPB regulator, or a second lab for exports). The manufacturer can never self-endorse a pass.

Formulate into product + mint signed QR (CP-7)

Formulation only proceeds if every input is COMPLETE_PASSED. Each unit gets an ed25519-signed QR token — a copied or edited QR fails signature verification.
Only passed batches can be selected.
Every event here is committed to the same ledger the collector and regulator read. Refresh the regulator dashboard after each step to watch the batch advance.
