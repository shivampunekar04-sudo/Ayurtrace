# Reference-data sources & provenance

This documents where every value in [`seed/src/index.ts`](../seed/src/index.ts) comes
from, what is **real** vs a tagged **estimate `[EST]`**, and where to obtain official
figures. It is the honest answer to "is this data made up?" — the taxonomy is real; the
kilogram quotas and exact boundaries are sourced estimates pending NMPB/State Board numbers.

## What is real (not estimated)

| Field | Basis |
|---|---|
| Botanical + common names | Standard taxonomy (e.g. *Withania somnifera* = Ashwagandha) |
| Officinal plant parts | Ayurvedic Pharmacopoeia of India; the part actually used per species |
| Harvest seasons | CSIR-CIMAP / CSIR-NBRI packages of practice (sowing/harvest calendars) |
| Conservation status (`endangered`) | **CITES Appendix II** — Sarpagandha, Kutki, Jatamansi; **WPA 1972**; **IUCN** (Jatamansi = Critically Endangered) |
| Zone geography | Coordinates sit over the **real districts named** (Tumakuru, Chikkamagaluru, Western Ghats, Chamoli); Kutki/Jatamansi correctly placed in the alpine Himalaya, not Karnataka |

## What is a tagged estimate `[EST]`

| Field | Why it's an estimate | Where to get the official number |
|---|---|---|
| `annualLimitKg` per (species, zone, season) | Set by regulators, not published as clean per-zone kg | **NMPB** (nmpb.nic.in) and **State Medicinal Plants Boards** — request the harvestable-limit notifications |
| `consumedKg` (year-to-date) | Would come from live collection records | Generated by the system itself once in use; seeded here to show GREEN/AMBER/RED bands |
| Exact polygon boundaries | Illustrative rectangles over the real districts | **FRLHT–ENVIS** MPCA network (envis.frlht.org); NMPB MPCA maps; draw in **geojson.io** or QGIS over ISRO **Bhuvan** |
| Post-harvest `declaredLossFactor` (per transform, sent at runtime) | Species/step-specific | CIMAP/ICAR fresh-to-dry ratios (e.g. Ashwagandha root ≈ 3–4:1 → ~65–75% loss) |
| DNA-sampling ratio (policy) | A regulator policy choice | Risk-based recommendation: 100% for endangered + export lots, statistical sample otherwise |

## How to replace the estimates

1. Get the official numbers from NMPB / your State Medicinal Plants Board (quotas, seasons)
   and FRLHT-ENVIS / a GIS export (zone polygons).
2. Edit [`seed/src/index.ts`](../seed/src/index.ts) — the shapes are already there; just
   swap values and paste real GeoJSON rings into `polygon`.
3. `cd seed && npm run build`, then re-run the tests (`chaincode/ayurledger: npm test`) and
   the gateway golden path to confirm nothing regressed.
4. Restart the gateway (`npm run start:live`) or `POST /admin/reset-demo` — the dashboards
   immediately reflect the new data.

## Source list

- **NMPB** — National Medicinal Plants Board, Ministry of AYUSH: nmpb.nic.in (MPCA network, GACP-MP guidelines, harvestable limits)
- **FRLHT / ENVIS Centre on Medicinal Plants**: envis.frlht.org (MPCA boundaries, conservation assessments / CAMP)
- **CSIR-CIMAP** (Lucknow) & **CSIR-NBRI** — agro-techniques / packages of practice (seasons, yields, fresh-to-dry ratios)
- **CITES** appendices; **Wildlife (Protection) Act 1972** schedules; **IUCN Red List** — conservation status
- **India Biodiversity Portal**; **ISRO Bhuvan** — geospatial base data for drawing zones
- **WHO GACP** for medicinal plants — good agricultural & collection practice baselines

> Everything tagged `[EST]` in the seed is a realistic, sourced placeholder — never presented
> to judges as an official figure. Swap in real numbers as they become available.
